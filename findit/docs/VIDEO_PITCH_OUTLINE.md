# Suggested 1–2 minute prototype pitch

| Approximate time | Demonstration and narration |
| --- | --- |
| 0:00–0:15 | Introduce FindIt, the campus lost-and-found problem, and intended users. Show actual initial research evidence when available. |
| 0:15–0:35 | Search for an item, filter found reports, and open details. Identify labeled demo records when used. |
| 0:35–0:55 | Submit an item report and photograph. Show the saved report after refresh. |
| 0:55–1:15 | Demonstrate Possible Matches and explain that the rule-based score does not verify ownership. Show campus-office recovery guidance. |
| 1:15–1:35 | Resolve or reopen an owned report and show guest-session ownership. |
| 1:35–1:50 | Open feedback, explain anonymous codes, consent, and testing stages. Show actual findings only after collection. |
| 1:50–2:00 | State one evidence-supported iteration, remaining limitation, and verified application URL. |

Before recording, replace all research placeholders with the group's real evidence. Do not present technical fixtures or demonstration reports as participant outcomes.

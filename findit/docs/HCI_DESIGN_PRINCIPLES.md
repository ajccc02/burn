# HCI design principles

| Nielsen heuristic | Implemented design choice |
| --- | --- |
| Visibility of system status | Loading states, upload percentage, submission feedback, report and session statuses |
| Match to the real world | Lost/found language, recognizable categories, campus location suggestions |
| User control and freedom | Cancel, edit, reopen, clear filters, and deletion confirmation |
| Consistency and standards | Shared controls, cards, badges, navigation, and form layouts |
| Error prevention | App/database validation, ownership checks, disabled pending actions, stable submission IDs |
| Recognition rather than recall | Visible categories, datalist locations, filters, and field labels |
| Flexibility and efficiency | Search, category shortcuts, URL filters, sorting, and personal reports |
| Aesthetic and minimalist design | White cards, restrained color, task-focused content, and mobile layouts |
| Error recovery | Field errors, retained input, retry controls, and stale-edit explanations |
| Help and documentation | About page, photo privacy reminders, campus recovery guidance, researcher guides |

Accessibility checks cover semantic landmarks, descriptive labels, meaningful alt text, keyboard focus, radio groups, live status/error announcements, touch targets, and contrast. Status badges include text. Reduced-motion settings disable decorative transitions.
